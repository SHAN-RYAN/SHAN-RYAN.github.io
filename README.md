# 🔮 RYAN's Tarot

AI-powered tarot reading application.

## Features
- 🃏 Multiple tarot decks (Rider-Waite, Marseille)
- 🤖 AI interpretation (Claude)
- 🌐 Bilingual (中文/English)
- 💾 Reading history & cloud sync

## Tech Stack
- React 19 + Vite
- Cloudflare Workers (backend)
- Supabase (user data)
